# 1. Введение

## Цели
Документ определяет требования к системе мониторинга технологического оборудования. Он описывает возможности системы, включая как функциональные, так и нефункциональные требования, ограничения и интерфейсы.

Данный документ предназначен для:
- Заказчиков - для проверки соответствия требований потребностям производства.
- Разработчиков - для создания на основе документа функционала системы.
- Тестировщиков - для создания сценариев тестирования и проверки соответствия системы требованиям.
- Персонала предприятия - для понимания принципов работы системы и ограничений при её эксплуатации.

## Границы применения
Разрабатываемое программное обеспечение является системой мониторинга технологического оборудования.
Система предназначена для повышения уровня контроля за работой технологического оборудования на производстве.
К области применения системы относятся:
- Сбор данных с датчиков, установленных на оборудовании.
- Привязка данных к конкретным единицам оборудования.
- Сравнение данных с нормативными значениями, соответствующими данному оборудованию.
- Определение режимов работы оборудования (нормальный, критический, аварийный).
- Объединение единиц оборудования в группы (узлы), поддержание многоуровневой иерархии.
- Графическое отображение параметров работы оборудования и иерархии узлов.
- Звуковое оповещение персонала о переходе оборудования в аварийный режим работы.
К области применения системы не относятся:
- Удаленное управление технологическим оборудованием.
- Поиск и хранение документации к оборудованию.
